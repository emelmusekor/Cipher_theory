# 암호의 역사와 컴퓨터의 탄생

학생이 수업 시간에 바로 열어 두고 눌러 보며 쓰는 체험형 웹페이지입니다.

## 실행 방법

1. `D:\Cipher_theory\index.html` 파일을 브라우저에서 엽니다.
2. 원하는 섹션으로 바로 이동해 입력을 바꾸고 버튼을 눌러 보며 결과를 관찰합니다.
3. 문자 시각화와 함께, 각 섹션의 하드웨어 그림이 어떻게 반응하는지도 같이 봅니다.

## 포함 모듈

- 스키테일 전치 암호 실습, 표 읽기 시각화, 막대와 가죽 띠 그림
- 시저 암호 변환, 휴리스틱 추정, 수학적 최적해, 시저 원판 그림
- 비제네르 암호, 반복 키 스트림 시각화, 다중 원판 그림
- 애니그마 로터 기계 구조 설명, 경로 애니메이션, 기계 본체 그림
- 크립 기반 봄브 탐색 체험, 정렬 시각화, 회전 드럼 그림
- 자기 자신 금지 검사를 포함한 튜링 머신 단계 실행기와 테이프 장치 그림
- CPU, 레지스터, 메모리, 표준입출력 구조 체험기와 블록형 하드웨어 그림

## 참고

현재 작업 환경에는 브라우저 자동 검증용 런타임(Node/Python)이 없어 정적 파일로 구현했고, 최종 렌더링과 애니메이션 감각은 브라우저에서 직접 확인해야 합니다.
