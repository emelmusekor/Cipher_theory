# 암호의 역사와 컴퓨터의 탄생

학생이 수업 시간에 바로 열어 두고 눌러 보며 쓰는 체험형 웹페이지입니다.

## 실행 방법

1. `D:\Cipher_theory\index.html` 파일을 브라우저에서 엽니다.
2. 원하는 섹션으로 바로 이동해 입력을 바꾸고 버튼을 눌러 보며 결과를 관찰합니다.
3. 문자 시각화와 함께, 각 섹션의 장치 그림이나 참고 이미지를 같이 봅니다.

## 포함 모듈

- 스키테일 전치 암호 실습과 Wikipedia 기반 참고 이미지
- 시저 암호 변환, 휴리스틱 추정, 수학적 최적해, Wikipedia 기반 참고 이미지
- 비제네르 암호와 반복 키 스트림 시각화, Wikipedia 기반 참고 이미지
- 애니그마 로터 기계 구조 설명과 개선된 로터 경로 시각화
- 크립 기반 봄브 탐색 체험과 드럼/램프 중심 시각화
- 자기 자신 금지 검사를 포함한 튜링 머신 단계 실행기와 상태 칩 시각화
- CPU, 레지스터, 메모리, 표준입출력 구조 체험기

## 참고

스키테일, 시저, 비제네르 섹션에는 Wikimedia Commons 이미지를 로컬 자산으로 포함했고, 페이지 안에 출처 링크를 함께 넣었습니다. 현재 작업 환경에는 브라우저 자동 검증용 런타임(Node/Python)이 없어 최종 렌더링과 애니메이션 감각은 브라우저에서 직접 확인해야 합니다.
