# 암호에서 컴퓨터로

학생들이 수업 시간에 바로 사용하도록 만든 체험형 암호학/컴퓨터과학 페이지입니다.

## 실행 방법

1. `D:\Cipher_theory\index.html` 파일을 브라우저에서 엽니다.
2. 위에서 아래 순서대로 각 실습을 진행합니다.
3. 각 섹션의 `움직이는 시각화` 패널을 보면서 암호화와 복호화의 흐름을 따라갑니다.

## 포함 모듈

- 스키테일 전치 암호 실습 + 표 읽기 애니메이션
- 시저 암호와 휴리스틱/수학적 해독 비교 + 알파벳 이동 시각화
- 비제네르 다중 치환 실습 + 반복 키 스트림 시각화
- 애니그마 로터 기계 실습 + 한 글자 경로 애니메이션
- 크립 기반 봄브 탐색 체험 + 정렬 시각화
- 튜링 머신 단계 실행기
- 폰 노이만 구조 미니 컴퓨터

## 참고

현재 작업 환경에는 브라우저 자동 검증용 런타임(Node/Python)이 없어, 정적 파일 형태로 구현했습니다.
